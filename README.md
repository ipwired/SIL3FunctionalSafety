TwinCAT 3 ADS Automation (C# / .NET)
A lightweight C#/.NET project for automating Beckhoff TwinCAT 3.1 using ADS. Supports reading/writing PLC variables, subscribing to notifications, and running simple automation routines.

Features
ADS connection (AMS NetId + port)

Read/write PLC variables

OnChange / cyclic notifications

Config‑based PLC target

Minimal, service‑oriented structure

Requirements
TwinCAT 3.1 (XAE or runtime)

.NET 6+ or .NET Framework 4.7.2+

NuGet: TwinCAT.Ads
